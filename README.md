 Gym Churn Prediction and Customer Retention Strategy📝 OverviewThis project focuses on building a robust machine learning model to predict customer churn (attrition) at a fitness center. The primary goal is to identify high-risk customers early to enable targeted intervention strategies, thereby maximizing customer lifetime value and improving overall retention rates.📊 Methodology and DataThe analysis followed a standard data science pipeline:Data Cleaning and Feature Engineering: Handled missing values, standardized names, and engineered critical features like:Membership_Tenure_DaysDays_Since_Last_VisitData Preprocessing: Categorical variables were processed using One-Hot Encoding. All numerical features were scaled using StandardScaler.Model Comparison: Two models were trained and evaluated: Logistic Regression (LR) and Random Forest (RF).Imbalanced Data Handling: Due to the severe class imbalance (74% Non-Churn vs. 26% Churn), model performance was primarily assessed using Recall and Precision for the Churn class (Class 1).🏆 Final Model Performance and SelectionThe Random Forest Classifier was selected as the final production model due to its superior Precision for the minority class, which is critical for trustworthy business interventions.MetricLogistic Regression (LR)Random Forest (RF) - SelectedAccuracy (Overall)0.900.97Recall (Class 1 - Churn)0.880.88Precision (Class 1 - Churn)0.781.00F1-Score (Class 1 - Churn)0.820.93Conclusion: The Random Forest model offers 100% certainty (Precision) when predicting a customer will churn, eliminating the costly allocation of resources to stable customers (zero False Positives).🔑 Key Actionable InsightsModel analysis revealed the quantitative importance of features, driving all strategic recommendations.Top Predictors of Churn Risk:RankFeatureImpact on Churn (Sign)Practical Insight1Visits_Per_MonthStrong NegativeThe strongest factor for retention.
